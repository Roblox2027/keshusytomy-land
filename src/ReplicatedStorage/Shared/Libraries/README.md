# Libraries

Codigo de terceros o modulos internos de proposito general
(pooling, throttling, tabla de transicion, etc.).

Reglas:

- Versionados dentro del repositorio, sin dependencias externas.
- Deben ser puros (sin dependencia de servicios de Roblox) cuando sea posible.
- Cualquier licencia de terceros debe documentarse en `docs/licenses.md`.
